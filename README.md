# Glass Launcher

A free, self-made Android launcher with a frosted-glass look (Android 12+).

## Build it
**Option A: Android Studio (easiest, needs a computer)**
1. Install Android Studio, choose "Open", pick this folder.
2. Wait for the Gradle sync, plug in your phone (USB debugging on), press Run.

**Option B: GitHub builds the APK for you (free)**
1. Create a GitHub repo and upload this whole folder, keeping the folder structure.
2. Open the Actions tab, run "Build APK".
3. Download the `GlassLauncher-debug` artifact and install `app-debug.apk`.

## Use it
Settings > Apps > Default apps > Home app > Glass Launcher.
Tap "Wallpaper" to pick a photo. Long-press an app to add it to the dock.
